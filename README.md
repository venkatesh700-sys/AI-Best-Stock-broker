# AI: The Best Stock Trader

Automated market analysis, 5,200 agent swarm decision engine, paper trading portfolio, and daily post-market retrospective learning engine.

## Features
- **5,200 Agent Swarm:** Multi-agent group debate (MAD) architecture across technical, volume, bullish, bearish, and news squads.
- **Autonomous Execution:** Morning signal generation and 4:00 PM IST retrospective overnight retraining.
- **Dynamic Data:** Zero hardcoded tickers—fetches Nifty universes live.
- **Telegram Bot Integration:** Automated alerts for picks and P&L breakdown.
- **365-Day Retention:** FIFO memory bank for rolling performance tracking.
